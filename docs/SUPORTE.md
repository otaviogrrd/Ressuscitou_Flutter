# Suporte — Ressuscitou

Aplicativo de apoio aos salmistas para ensaios, consultas e preparações dos cantos do Caminho Neocatecumenal.

Contato: [otavio.grrd@gmail.com](mailto:otavio.grrd@gmail.com).

Ao relatar um problema, informe o modelo do aparelho, a versão do sistema, a versão exibida em Sobre e os passos para reproduzi-lo. Não envie senhas ou conteúdo pessoal desnecessário.

## Dúvidas frequentes

- O catálogo pode ser consultado offline após a instalação. Atualizações e downloads de áudio exigem internet.
- A consulta de atualização do catálogo ocorre ao iniciar o app. A propagação de uma alteração hospedada no GitHub pode levar alguns minutos.
- O app não exige conta nem assinatura.
- Os dados de listas e anotações são locais; utilize as opções de backup/exportação antes de remover os dados do aplicativo.

Este aplicativo não deve ser utilizado em celebrações; destina-se a ensaios, consultas e preparações.
