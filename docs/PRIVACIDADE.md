# Privacidade — Ressuscitou

O Ressuscitou é uma ferramenta de apoio aos salmistas para ensaios, consultas e preparações. Não exige conta, não inclui publicidade e não integra ferramentas de análise de comportamento ou rastreamento publicitário no código desta versão.

## Dados no aparelho

Listas de cantos, anotações, transposições, capotraste e preferências ficam armazenados no aparelho. Os áudios baixados também são salvos localmente. A exportação e o compartilhamento de listas ou cópias de segurança são iniciados pelo usuário, que escolhe o destino.

## Conexões com serviços externos

O aplicativo consulta arquivos hospedados no GitHub para atualizar o catálogo e mensagens e para baixar áudios. Nessas conexões, o provedor pode processar informações técnicas da requisição, como endereço IP, conforme sua própria política: https://docs.github.com/pt/site-policy/privacy-policies/github-general-privacy-statement.

A busca da distribuição atual é executada localmente. Uma integração opcional com um serviço de busca, se habilitada em uma distribuição futura, deverá ser refletida nesta política antes da publicação. Links externos e mensagens de e-mail são abertos pelo aplicativo escolhido no aparelho e estão sujeitos às práticas do respectivo serviço.

## Controle do usuário

O aplicativo permite apagar os áudios baixados. Listas e anotações podem ser gerenciadas no próprio app. A remoção dos dados do aplicativo ou sua desinstalação elimina os dados locais, observadas as opções de backup do sistema operacional. Não há conta de usuário para excluir.
